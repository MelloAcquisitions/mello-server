# Version-pinned deliberately.
#
# This was unpinned. A free-tier Render service redeploys on every push and
# reinstalls from scratch, so an upstream release the same afternoon can
# break the live call path with no code change on your side and no obvious
# cause. Bump these on purpose, not by accident.
#
# To update: change a pin, deploy, confirm / returns healthy and one test
# call completes, then move on. Never bump several at once.
#
# ---------------------------------------------------------------------------
# THE PYDANTIC PIN IS LOAD-BEARING. DO NOT LOWER IT.
#
# Render builds on the newest Python it supports — 3.14.3 as of Sept 2026 —
# and it picks that by default. pydantic 2.10.4 pulls pydantic-core 2.27.2,
# which has NO prebuilt wheel for 3.14, so pip fell back to compiling it
# from Rust source. Render's build image mounts the cargo registry
# read-only, so that compile can never succeed:
#
#   error: failed to create directory `/usr/local/cargo/registry/cache/...`
#   Caused by: Read-only file system (os error 30)
#   maturin failed  ->  error: metadata-generation-failed
#
# pydantic 2.12.0 is the FIRST release whose pydantic-core ships cp314
# wheels. 2.12.5 pins pydantic-core 2.41.5, which does. Every other package
# below already had 3.14 wheels, including the four other compiled ones
# pulled in transitively (lxml, jiter, charset-normalizer, markupsafe) —
# verified by resolving this whole file against 3.14 with
# --only-binary=:all:, which succeeded with zero source builds.
#
# So this file now builds on 3.12, 3.13 AND 3.14. The .python-version file
# at the repo root is belt-and-braces, not the fix — if it goes missing or
# Render ignores it, the build still works.
# ---------------------------------------------------------------------------

# which slim/alpine base images do not ship. Without this,
# ZoneInfo("America/Monterrey") raises ZoneInfoNotFoundError at import of
# mello_time — and ZoneInfo("America/Chicago") raises inside
# is_within_calling_hours(), which is what decides whether it is legal to
# dial someone right now.
